关键结论速查

关键运作机制结论（以 ChatGPT Business 为主）

计费周期 & 成员能否自选

成员不能自选周期；整个工作区统一一个周期（Owner 定）；年付新加成员并入年付、对齐同一续费日。

不能同一工作区月/年混用；改周期只能整个工作区续费时整体切换。⚠️ 微软 Copilot Business 无「纯月付」——只有年度承诺（可按年/按月扣款，均锁 12 月）。

关键

续订 / 到期：全员一并失效

是——一个工作区 = 一份订阅 = 统一到期日；Owner 取消 / 到期不续 / 欠费 → 全体成员在同一时点一并失去 Business 访问。

后台「新增日期」只是加入日、≠ 各自到期日；不同日期加入的人全部对齐到工作区统一续费日；最迟用到当前账期末再整体停用；订阅费不退；仅 Owner 能续/停/重新激活。

移除成员 / 减席降费

可随时移除成员（立即失访）；但「移除 ≠ 退款/降费」，只释放席位供改派；要降费须主动减少「席位总数」。

年付移除不立即退款、降费体现在后续/续费（OpenAI/Claude）；月付 / Google Flexible 可随时降席位、下账期生效。

编程 Agent 在哪些席位

ChatGPT 席位本身已含 Codex（若全是 ChatGPT 席位即无需单独设 Codex）；Claude Code 含在所有 Team 席位（高级席位 5x 用量）。

独立「Codex 席位」是给只用 Codex、不要 ChatGPT 的人（无月费、按量）；限额按「持有的席位类型」生效。

Agent 用量怎么算

都是「5 小时滚动窗口 + 每周上限」；包含用量按 rate limit（消息/任务数）、不耗积分；Codex 超额按 API token 折算成积分。

Claude Code 与 claude.ai 聊天共用同一配额；Codex 与 ChatGPT for Excel、Workspace Agents 共用「agentic 池」（仍是每席自己的桶）。

关键

积分(credits) 是什么

积分是「超额阀门」、不是白送额度；日常包含用量不耗积分。1 积分 = US$0.04。

后台「每月用量限額 300 积分」= 每个 ChatGPT 席位每月最多花的「支出上限」（≈$12），非发放额度；余额=0 且自动增值关闭 → 实际可超额 = $0（但包含用量照常可用）。

关键

会不会被一个人用光全队

包含额度（每席位独立）= 不会；超额买的「workspace credits 共享池」= 会（默认无人均上限）。

共享池被一个人 / 失控脚本耗尽 → 全队该超额功能不可用、直到充值；每人 per-seat 包含额度仍可用。

关键

如何防止被一个人吃光（后台）

在「每月用量限額」按席位类型 / 按具体用户设月度积分上限（默认不设、须主动开）。

ChatGPT 席位有上限即可护住其 Codex；「Codex 席位」上限只对独立 Codex 席位生效；自动增值若开务必设月度上限；开「用量提示」告警；仅 Owner 可配。

关键

数据导出 / 迁移

⚠️ ChatGPT Business 工作区不支持数据导出；停用后数据保留但导不出、不能并入新工作区。

数据保留：默认无限期（至用户删除）、自定义保留最低 90 天（不支持零保留，ZDR 仅 API）、删除内容 30 天内清除（内部备份再 ≤30 天）；停用后数据保留可恢复，但「永久删除前保留天数」官方仍未公布。不要等订阅过期才想导出数据。
